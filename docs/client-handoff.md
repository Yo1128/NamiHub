# NamiHub 面向三个客户端的接入约定

适用于 NamiHub 0.2.x、Dart SDK 0.2.x 和 HTTP API v1。 在线指客户端通过局域网读取已配对主机的共享资源。三个应用分别维护自己的界面、资料库、进度和下载副本。

| 客户端 | 点开共享条目的默认动作 | 用户主动选择的次要操作 | 当前接入情况 |
|---|---|---|---|
| NamiView · Windows | 在线播放或从上次位置继续，拖动时按需取数 | 下载本集到本机，供离线观看 | 已支持八位码配对、共享列表直接播放、单集下载和离线续播；需要批量整理时可多选加入媒体库。 |
| NamiRead · Android | 在线阅读，从首屏或上次阅读位置取正文，翻章再取所需内容 | 下载整本到本机，供离线阅读 | 0.7.0 已接入八码配对、UTF-8 TXT 分段和 EPUB 按章读取。加入书架和完整下载有独立入口。 |
| NamiListen · Windows | 在线收听，从当前曲目开始缓冲，拖动或换曲时更新读取位置 | 下载所选曲目到本机，供离线收听 | 已有本地曲库与原生音频开发基础。Hub 配对、在线音频输入和下载均待接入。 |

## 连接与读取

各项目可以固定使用独立 SDK 包，以相对路径依赖自己的 `third_party/nami_hub_client`。同一局域网首次连接只输入主机显示的八位码，保留前导零。使用 `HubLan.pair(code, clientName)`，由各应用单独保存主机身份、地址、证书指纹及安全存储中的会话。重开用 `HubLan.restore(origin, pin, session)` 并保存返回的地址。手动填写地址和指纹的入口用于旧主机或发现受限的网络。[八码配对与恢复](lan-pairing.md)

- **浏览与收藏。** 调用 `hub.resources(type: 'video')` 获取视频，书籍和音频分别传 `'book'` 和 `'audio'`。收藏或加入资料库只需保存元数据和来源关联。以 `(hubId, resourceId)` 标识来源，用 `contentVersion` 区分版本。地址、显示名称和播放临时 URL 均可变化。
- **在线打开。** 使用 `hub.read(item, start: firstByte, end: lastByte)` 获取当前版本所需字节，两端位置均包含在范围内。支持顺序缓冲、向前或向后定位，离开条目时释放旧读取。允许少量预读，小文件也可能自然读完；在线使用不建立整份下载任务，也不据此显示「已下载」。原生播放器通过 SDK 适配输入，或自行对网络连接执行同等的证书、鉴权与版本检查。[HTTP 内容接口](api-v1.md)
- **下载到本机。** 仅在用户选择后调用 `hub.download(item, target)`，由应用为该来源及版本确定私有目标。重试时复用同版部分文件；校验长度和 SHA-256、完成客户端所需处理后，才发布为离线副本。新版本失败时保留已验证的旧版。移除下载后保留来源和进度，不触碰 Hub 原件。
- **断线与恢复。** 主机不可达时，有已下载的适用版本就允许本机继续；否则保留位置，提供「重试连接」。401 引导重新配对；412 刷新元数据，丢弃失效的在线缓冲，下载重试使用对应版本的部分文件。对旧版保留版本标识和历史。错误恢复不会替用户启动下载。

## 跨端联调与验收

| 操作 | 通过条件 |
|---|---|
| 空缓存配对，打开足够大的书、视频或音轨 | 只输入八位码。可在整份传完前读到正文、看到画面或听到声音。记录首次可用时刻和当时已传字节；客户端没有离线任务或「已下载」标记。 |
| 加入书架、媒体库或曲库，再定位到未读位置 | 加入时只保存关联。按需读取所选章节或时间点，记录主机的 `206` 与请求范围；阅读器书签或播放器进度可以恢复。 |
| 主动选择「下载到本机」，完成后关闭主机并重启客户端 | 对应版本通过整文件校验。能离线打开同一资源并继续到之前的位置，无需访问主机；未下载的另一项能看到重连入口。 |
| 断网后重试、传输中换版、移除本机下载 | 部分文件不会显示为可离线；失败或取消保留已有可用版本。移除后可在主机在线时重新打开原件，个人进度保留。 |

在独立 SDK 包中运行 `dart pub get` 和 `dart run example/pair_lan.dart` 可先验证八码配对与目录读取。Hub 命令行联调包可用 `.\Start-NamiHub.ps1 -Lan -TraceReads` 观察范围。固定样本包括《灯塔手记》TXT、tide-notes.epub、MP3 与 WAV 音轨以及 harbor-seek.mp4。短样本用于格式验证；首屏、首帧或首声的传输量另用超过客户端预读范围的素材测量。各端独立记录构建号、样本、设备与结果。[固定样本清单](../fixtures/catalog.json) · [Hub 传输层已有验证记录](verification-windows-0.2.0.json)
